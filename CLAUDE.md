# quicknote – notes for AI coding agents

quicknote is a small CLI that stores notes as Markdown files.

## Conventions
- Source lives in `src/`. Keep functions small and pure where possible.
- Use `node --test` for tests.
- Prefer plain ESM imports; no build step.

## Style
- Two-space indentation, no semicolons omitted.
- Keep the public API in `src/index.js` stable.
